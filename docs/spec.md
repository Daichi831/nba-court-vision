# アプリ仕様書

## 概要

NBA の選手スタッツを閲覧するための個人用 Web アプリ。チーム・選手を選択すると今シーズンの平均スタッツとゲームログを確認できる。

## 画面フロー

```
サイドバー：チーム選択（ドロップダウン）
  → チームロゴ・チーム名表示
  → 選手選択（ラジオボタン）
      ↓
メインエリア：今シーズン平均スタッツ
  → 能力バランス（六角形チャート）
  → ゲームログ
```

## 表示項目

### 平均スタッツ
| 項目 | 説明 |
|------|------|
| 得点 | PTS（1試合平均） |
| リバウンド | REB（1試合平均） |
| ORB | オフェンスリバウンド（1試合平均） |
| DRB | ディフェンスリバウンド（1試合平均） |
| アシスト | AST（1試合平均） |
| ブロック | BLK（1試合平均） |
| スティール | STL（1試合平均） |
| ターンオーバー | TOV（1試合平均） |
| 試合数 | GP |

### 能力バランス（六角形チャート）
| 項目 | 説明 |
|------|------|
| 得点力 | PTS（1試合平均）のリーグ内パーセンタイル |
| 効率性 | True Shooting %（TS_PCT）のリーグ内パーセンタイル |
| プレーメイク | Assist %（AST_PCT）のリーグ内パーセンタイル |
| リバウンド能力 | Total Rebound %（REB_PCT）のリーグ内パーセンタイル |
| 影響力 | PIE（Player Impact Estimate）のリーグ内パーセンタイル |
| ディフェンス力 | Defensive Rating（DEF_RATING）のリーグ内パーセンタイル |

各指標は `leaguedashplayerstats` から取得した `*_RANK` を基に `(対象人数 - 順位) / (対象人数 - 1) * 100` でリーグ内パーセンタイル（0〜100、100に近いほど上位）に変換し、六角形チャートとして表示する。DEF_RATINGは値が低いほど守備が良いため、`DEF_RATING_RANK` も値が低いほど上位（1位）になる順位が採用されている。

### ゲームログ
| 項目 | 説明 |
|------|------|
| 日付 | GAME_DATE |
| 対戦 | MATCHUP |
| 勝敗 | WL |
| 分 | MIN |
| 得点 | PTS |
| リバウンド | REB |
| ORB | オフェンスリバウンド |
| DRB | ディフェンスリバウンド |
| アシスト | AST |
| ブロック | BLK |
| スティール | STL |
| ターンオーバー | TOV |
| FG | 成功-試投 (FG%) |
| 3P | 成功-試投 (3P%) |
| FT | 成功-試投 (FT%) |

## シーズン設定

`app.py` の `CURRENT_SEASON` 定数でシーズンを管理する。シーズンが変わったらここだけ更新する。

```python
CURRENT_SEASON = "2025-26"
```
